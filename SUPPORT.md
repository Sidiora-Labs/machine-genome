# Support

Machine Genome is experimental open-source infrastructure.

- Use a **bug report** for reproducible implementation defects.
- Use a **protocol proposal** for wire-format or semantic changes.
- Use a **documentation issue** for unclear or missing guidance.
- Use [private vulnerability reporting](SECURITY.md) for security concerns.

The project does not currently offer guaranteed response times, commercial
support, protocol certification, legal advice, model-vendor verification, or
recovery of lost controller keys.

When asking for help, include the `mgs version` output, operating system,
relevant command with secrets removed, expected behavior, actual error, and a
minimal synthetic record where possible.
