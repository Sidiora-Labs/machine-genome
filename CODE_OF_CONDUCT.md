# Community code of conduct

Machine Genome contributors are expected to make technical collaboration safe,
rigorous, and accessible.

## Expected behavior

- debate claims and evidence without attacking people;
- state uncertainty, conflicts of interest, and trust assumptions;
- welcome corrections and questions from different experience levels;
- protect private and embargoed information;
- respect licensing, attribution, and service access policies;
- avoid language or behavior that is harassing, discriminatory, threatening,
  sexualized, or deliberately disruptive.

## Scope

This applies in repository issues, pull requests, reviews, discussions, release
work, security coordination, and project events or private channels where
someone is representing the project.

## Enforcement

Report conduct concerns privately to repository maintainers. If confidentiality
is important, the private vulnerability-reporting channel described in
[SECURITY.md](SECURITY.md) may be used and labeled as a conduct report.
Maintainers may edit or remove content, issue a warning, limit participation, or
ban a participant. Enforcement decisions should be proportionate, documented
to the affected parties, and avoid conflicts of interest.

Retaliation against a good-faith reporter is itself a violation.
